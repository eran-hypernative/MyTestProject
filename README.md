### אב־הטיפוס

קובץ יחיד, בלי תלויות. המנוע אמיתי: כל מיקום מחושב מפריטי ראיה דרך הנוסחה בסעיף 3.5,
ולא נקבע מראש. הנתונים בדויים במכוון — הקידוד (`direction`, `magnitude`) הוא עבודת
עורך אנושי לפי סעיף 7.3, וטרם נעשה.

מה ממומש: מודל הנתונים סביב ח"כ עם שיוך סיעתי מתוארך (3.1), פריטי ראיה ודירוג מקורות (3.2–3.3),
מיקום בסיס עם משקל נמוך ושומר נימוק (3.4), חישוב המיקום ומגש הטרם־מקוטלגות (3.5),
ארבעת הצירים וציר הסקטוריאליות במסך נפרד (4), הפתקים והחץ והאנימציה ומגירת הראיות
ומד הכיסוי (5.1–5.4), מנוע המשקולות (5.5), פרימיטיבי ה־RTL (6), ועמוד המתודולוגיה (9).

הקובץ כתוב בפורמט של Artifact ולכן אין בו תגיות `doctype`/`html`/`head`/`body`.
לפתיחה מקומית יש לעטוף אותו בשלד HTML מינימלי.
