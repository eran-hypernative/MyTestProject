### מצב הנתונים

**האפליקציה נטענת ריקה.** אין בה נתוני אמת ואין בה נתוני הדגמה, עד שיורץ הצינור.
זו התצוגה הנכונה לפי סעיפים 3.5 ו-5.4: אין ראיות, אין נקודה.

לבדיקת הממשק בלבד אפשר להוסיף לכתובת `?demo=1`. הנתונים שם בדויים לגמרי,
מסומנים בבאנר קבוע, ואינם קשורים לאף מפלגה אמיתית.

### הצינור

```
node harvest/harvest.mjs probe                  אימות הסכימה מול $metadata
node harvest/harvest.mjs pull --knesset 25      משיכה למטמון cache/
node harvest/build.mjs --knesset 25             תור סקירה אל data/review-queue.csv
#  כאן העורך ממלא direction ו-magnitude
node harvest/inject.mjs                         הזרקת הפנקס אל app/index.html
node --test "harvest/test/*.test.mjs"           בדיקות
```

הרבסטר לא מניח שמות שדות. הוא מגלה אותם מ-`$metadata`, ואם הסכימה השתנתה הוא נעצר
ומדווח מה בדיוק לא נמצא, במקום לכתוב בשקט נתונים שגויים. `probe` אינו מושך נתונים.

הקידוד (`direction`, `magnitude`) הוא עבודת אדם לפי סעיף 7.3. אף סקריפט כאן לא ממלא אותו.

### מה ממומש

מודל הנתונים סביב ח"כ עם שיוך סיעתי מתוארך (3.1), פריטי ראיה ודירוג מקורות (3.2–3.3),
מיקום בסיס עם שומר נימוק (3.4), חישוב המיקום ומגש הטרם־מקוטלגות (3.5), ארבעת הצירים
וציר הסקטוריאליות במסך נפרד (4), הפתקים והחץ והאנימציה ומגירת הראיות ומד הכיסוי (5.1–5.4),
מנוע המשקולות (5.5), פרימיטיבי ה־RTL (6), הרבסטר והמטמון ותור הסקירה (7), ועמוד המתודולוגיה (9).

`app/index.html` כתוב בפורמט Artifact ולכן אין בו תגיות `doctype`/`html`/`head`/`body`.
